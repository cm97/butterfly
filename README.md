# Butterfly 🦋

A web page that prints millions of dollars.

No printer required. Candle required.

## How it works

1. Open `index.html` in any browser.
2. Light the candle.
3. Watch the money print.

## The science

The candle is the power source. The browser is just the display.
Without the candle, it's just a webpage. With the candle, it's a **money printer**.
